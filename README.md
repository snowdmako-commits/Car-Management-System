# 🚗 Car Management System

A simple **Car Management System** developed using Python. This project allows users to manage car records through a command-line interface.

## ✨ Features

- **Add Car** – Add a new car with brand, model, price, year, and color.
- **Show All Cars** – Display all registered cars.
- **Update Car** – Update car price or color using its ID.
- **Delete Car** – Delete a car using its ID.
- **Filter / Sort Cars** – Sort cars by price or production year.
- **Error Handling** – Handle invalid inputs using `try-except`.

## 🛠️ Technologies Used

- Python 3
- Functions
- Lists
- Dictionaries
- Lambda Functions
- Sorting (`sorted()`)
- Exception Handling (`try-except`)
